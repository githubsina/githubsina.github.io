# 网站文字 · Site text

网站上所有中英文文字都在这个文件夹里，改这里就行。

| 文件 | 内容 |
|---|---|
| `home.md` | 首页：自我介绍、桌上每个小物件的纸条、奖项、关于我 |
| `projects/1-embodied.md` … `5-amblyopia.md` | 每个项目一份：标题、简介、数字、正文、图片说明 |
| `xr-lab.md` | XR Lab 页的大标题（项目卡片的一句话简介在各项目文件的 `short`） |
| `research.md` | 研究页：介绍、标签、教育经历、教学 |
| `gallery.md` | 摄影页：标题、相册名字 |
| `common.md` | 每页都有的菜单、语言按钮、项目页的小标签 |

## 怎么改

```
## note.tea.text
EN: English text
中: 中文
```

- 只改 `EN:` 和 `中:` 后面的字；`##` 那一行是标签，不要改。
- 列表用编号（`award.1`、`award.2` …），几栏之间用 ` | ` 隔开。多写一个编号就多一行，删掉就少一行。
- 某种语言空着不写，会自动用另一种语言。
- `>` 开头的行是给你看的说明，不会出现在网站上。
